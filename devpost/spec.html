Acorn 技術仕様

アプリ（Expo）がルールとデータのすべてを持ち、API サーバー（FastAPI）は Jev に聞いて pt に換算するだけ。Jev には区分を選ばせ、計算はコードで行う。

全体の構成

アプリ（TypeScript） API サーバー（Python） 外部サービス

Core Journey をシステムで追う

部品とファイル

Domain mobile/src/domain/
  • clock.ts：アプリ時刻 = 実時刻 + ずらし。週の月曜と日付キー → prd: デモ用の時間操作 / 週のリセット
  • week.ts：週の切り替え、件数チェック、引き継ぎ → prd: ミッションとその pt
  • clears.ts：クリアの可否、取り消し（30 分以内かつ残高 ≥ pt） → prd: クリアと取り消し
  • balance.ts：残高 = クリアの合計 − 交換済みの合計 → prd: 報酬とその価格
  • setup.ts：準備フローの次のステップ → prd: Screens and Layout / 予算
Screens mobile/app/
  • setup.tsx：予算 → 報酬 → ミッション → 採点（読み込み中 / ステータス / エラーと再試行）
  • index.tsx：ホーム（残高・タイムライン・クリア / 取り消し）
  • shop.tsx：ショップ（価格・分布・交換・追加。最大 5 件、交換済みは数えない）
  • _layout.tsx：フォント、ナビ、デモ用の時間操作、トースト
Store / API Client / UI mobile/src/
  • storage/store.ts：キー acorn:v1 に JSON を 1 つ保存。useAcorn()
  • api/client.ts：EXPO_PUBLIC_API_URL の /judge/* を呼ぶ
  • ui/：Window、StatusDistribution、Timeline、Toast、DemoClock、theme
API Server api/src/acorn_api/
  • main.py：GET /health、POST /judge/missions、POST /judge/reward。CORS は localhost:8081
  • jev.py：AsyncTypeSafeClient。テストで差し替えられる 1 つの関数
  • pricing.py：区分を pt に換算（pytest）
  • schemas.py：Pydantic の型
POST /judge/missions  { budgetUsd, missions:[{id,name,kind}] }
  → { missions:[{ id, pt, judgement:{choice, probabilities, confidence} }] }
POST /judge/reward    { budgetUsd, name }
  → { pt, mode:"price"|"period", judgement:{...} }
失敗 → 502 { detail: "Jev の判定に失敗しました" }
Data Model AsyncStorage: acorn:v1
{ version: 1,
  budgetUsd: number | null,
  clockOffsetMs: number,
  rewards: [{ id, name, pt, mode, judgement, status: "available"|"redeemed", ... }],
  week: { weekStart: "YYYY-MM-DD", status: "setup"|"scoring"|"active", missions: [...] },
  previousMissions: [...],
  clears: [{ id, missionId, weekStart, date, pt, clearedAt }] }

残高は保存せず毎回計算する。API サーバーは何も保存しない。

Look and Feel mobile/src/ui/theme.ts
  • フォント：DotGothic16（日本語対応のドット風）を見出し、ボタン、数値に使う
  • 色：クリーム #f3efe2 / こげ茶 #2b2620 / どんぐり #a5642e / 葉 #4f8a5b / 空 #3f6fa6 / ベリー #b8435a（このページの配色と同じ）
  • RPG の窓（太い 3px の枠、角丸 8px）、「▶」付きのボタン、ステータス画面は上位 3 つを % と横棒で
  • モバイル幅（最大 430px 程度）、Web では中央に寄せる

失敗したとき

Jev / API サーバーの失敗

エラーと「▶ もう一度」を出す。週は「採点中」のままで、クリアできない。

日本語の判定の質（未確認）

ビルドの最初に実際の名前で試す。おかしければ質問の書き方を調整する。

残高不足のすり抜け

保存の直前にもう一度確かめる。足りなければトーストを出して何も変えない。

起動と収録

cp .env.example .env        # TYPESAFE_API_KEY を入れる（コミットしない）
docker compose up --build   # API → http://localhost:8000
cd mobile && npm install
npx expo start --web        # アプリ → http://localhost:8081

ブラウザのモバイル表示で録画する。提出には動画と公開リポジトリが必要で、デプロイは任意（共有するなら自宅の k8s）。
